# PIVOT 双语研究博客

双击 `index.html` 即可打开。右上角 **EN / 中文** 切换整篇文章，页面会记住所选语言；也支持 `?lang=en` 和 `?lang=zh`。

- 八节主线：稀疏奖励 → 两类指导各自的局限 → PIVOT → 干预时机 → KL 方向 → 训练配方 → 实验结果 → 未来方向。
- 六张论文原图，点击可放大；正文、图注、图片替代文本和表格说明支持双语。
- 逻辑游戏／数学结果可切换；案例细节可展开；桌面侧边目录显示当前阅读位置。
- 手机布局已适配，宽表格可横向滚动。尊重系统的减少动画设置。
- 论文链接指向 `assets/pivot-paper.pdf`，已包含最新十位作者及单位信息。

## 文件

- `index.html`：中英文内容与表格，直接编辑即可。
- `styles.css`：配色、字体、响应式布局。
- `script.js`：语言切换、结果分组、目录状态与图片放大。
- `assets/`：原图导出的 SVG、论文 PDF、网页图标和本地字体。
- `SOURCE_NOTES.md`：图表来源与数字口径。
- `preview.png`：桌面与手机的实际浏览器效果。

无需安装依赖，无需联网加载字体或图表。若希望通过本地 HTTP 预览，可在本文件夹执行：

```bash
python3 -m http.server 8765
```

随后打开 `http://localhost:8765/`。目录也可作为普通静态站点文件使用。

字体许可证保留在 `assets/fonts/`。中文字体做了本地字符子集，新增文字如不在子集中，会使用设备自带中文字体。
